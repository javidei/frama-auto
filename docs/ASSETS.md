# Recursos visuales

- `public/images/logo-original.png`: logotipo proporcionado por el usuario en la conversación de referencia. Se presenta recortado por CSS para sustituir el subtítulo antiguo; el archivo original se conserva.
- `public/images/hero.png`: portada generada con la herramienta integrada de imágenes. Prompt: fotografía editorial cinematográfica de interior de coche negro, cuero coñac y costuras doradas a la derecha, espacio oscuro a la izquierda, sin texto ni personas.
- `public/images/mercedes.png`, `bmw.png`, `audi.png`: imágenes generadas con la misma herramienta integrada. Prompts: atlas fotográfico 3×3 sin márgenes de una berlina Mercedes Clase C negra, una BMW Serie 3 plateada y un SUV Audi Q3 gris respectivamente; orden principal, frontal, trasera, lateral izquierdo, lateral derecho, interior, volante/salpicadero, plazas traseras y llanta. Estudio de hormigón oscuro y luz suave.

Las ilustraciones son sintéticas, no fotografías de unidades de FRAMA AUTO. Puede haber diferencias de generación, acabado y equipamiento respecto a los datos ficticios del JSON; la interfaz lo indica. Los archivos permanecen dentro del proyecto y no requieren servicios externos para visualizarse.
