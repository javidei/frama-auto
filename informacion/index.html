TRANSPARENCIA DESDE EL PRINCIPIO

Una demo con recorrido.

Contenido ilustrativo

Esta web muestra una propuesta para FRAMA AUTO, dedicada a importación y venta de vehículos. Los coches, precios, kilometrajes, características y equipamientos son ejemplos ficticios. No representan vehículos disponibles, reservas, garantías ni ofertas comerciales. Las imágenes de vehículos e interiores están generadas por IA y pueden no coincidir con la versión descrita.

Catálogo y futura administración

La información se carga de un JSON local mediante una capa de acceso a datos del servidor. Está preparada para sustituir ese origen por una base de datos sin rehacer las pantallas. No existe un panel de acceso real ni credenciales de prueba. Esta publicación en GitHub Pages es estática: no tiene API de escritura ni panel de administración. La edición con servidor conserva esas operaciones deshabilitadas.

La fase de base de datos requerirá autenticación real y comprobación de permisos en cada operación del servidor. Se prevén roles de propietario, editor y lector, con permisos separados para editar, publicar y administrar usuarios. Ocultar un botón nunca sustituirá el control de permisos.

Privacidad de esta prueba

El formulario solo prepara una vista previa en tu navegador. No envía mensajes ni guarda su contenido. No se utilizan herramientas de analítica ni cookies propias de seguimiento en esta aplicación. El alojamiento puede utilizar sus mecanismos de acceso y registros técnicos. Los filtros se reflejan en la URL para conservar la selección al recargar; evita escribir datos personales en ellos.

Antes de una publicación comercial habrá que incorporar los datos legales y de contacto reales, las condiciones aplicables y una política de privacidad acorde al funcionamiento definitivo.
